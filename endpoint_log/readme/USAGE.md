To log the calls of an endpoint, go to *Settings > Technical > Endpoints*, open the
endpoint and check *Log Requests* in the *Request* group. The option is visible to
members of the *API Log Access* group.

The *Logs* smart button on the endpoint shows its logs. The logs of all endpoints are
listed in *Settings > Technical > Endpoint Logs*.

Each logged response carries an `API-Log-Entry-ID` header with the ID of its log, which
helps to find the log of a given call.
